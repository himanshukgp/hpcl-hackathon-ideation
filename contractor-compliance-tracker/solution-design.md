# Solution Design

## Workflow

1. Contractor profile is created in Power Apps.
2. Documents and expiry dates are uploaded.
3. UiPath sends reminders before document expiry.
4. Fluid AI answers readiness questions.
5. Non-compliant contractors are blocked from approval list.

## Compliance Areas

- Safety induction
- Medical fitness
- Insurance
- Work order validity
- Gate pass
- PPE checklist
