# Permit-to-Work Automation Assistant

A digital workflow for creating, validating, approving, tracking, and closing work permits for terminal activities.

## Core Idea

Work permits for hot work, confined space entry, electrical isolation, height work, excavation, and maintenance shutdowns require strict checks and approvals. This solution makes permit handling faster, safer, and more traceable.

## Tools

- Power Apps: permit request, approval, and closure screens
- UiPath: approval routing, reminders, PDF permit generation
- Fluid AI: permit checklist assistant and missing-field checker
