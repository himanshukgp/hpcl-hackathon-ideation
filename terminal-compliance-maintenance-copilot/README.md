# Terminal Compliance & Maintenance Deadline Copilot

An automation system for HPCL terminal teams to track periodic maintenance, testing, statutory checks, owner assignments, due dates, evidence, reminders, and escalation.

## Core Idea

Terminal operations involve many recurring tasks: tank inspections, fire equipment checks, pump maintenance, electrical testing, calibration, safety audits, and statutory submissions. These are often tracked manually through Excel, registers, email, and informal reminders.

This project creates a single operational layer where tasks are recorded, monitored, reminded, completed with evidence, and summarized using AI.

## Tools

- Power Apps: task dashboard, mobile completion form, evidence upload
- UiPath: data import, reminder automation, escalation, report generation
- Fluid AI: natural language compliance assistant and summary generator

## Best Demo Moment

Ask Fluid AI: "What compliance items are overdue this week and who owns them?" Then show UiPath sending escalation emails and Power Apps updating the task status.
